PROJECT DEVELOPMENT AGREEMENT (PDA): AUTOBI PHASE 2 – INTELLIGENCE & INSIGHTS

This document serves as the official execution plan for Milestone 2 of the AutoBI Studio project. It outlines the technical transition from a data storage tool to an AI-driven business intelligence platform.

1. PROJECT OBJECTIVE
To provide a Zero-Cost, AI-Guided environment where users can automatically generate dashboards from cleaned datasets, customize them in a Power BI-style canvas, and interact with data using a Retrieval-Augmented Generation (RAG) chat interface.

2. CORE ARCHITECTURE & FEATURES

A. The "AI Designer" (Dashboard Generation)
- Logic: A backend service that performs EDA (Exploratory Data Analysis) on CSV/Excel files and generates a JSON metadata file containing chart suggestions (KPIs, Bar, Line, Pie).
- Persistence: Dashboards are saved to the NeonDB (PostgreSQL) dashboards table.
- Visuals: Powered by Recharts for high-quality, animated web visualizations.

B. The "Power BI" Studio (Customization Canvas)
- Canvas Elements: A responsive grid where charts can be resized, moved, and updated.
- Visuals Library: Users can add new charts (KPI cards, Donut charts, Area charts) using simple drag-and-drop.
- Integration: Every auto-generated dashboard includes a "Edit in Studio" option for manual refinement.

C. The RAG Insights Hub (Conversational Intelligence)
- Dedicated Section: A standalone "Chat with Data" interface.
- RAG Flow: 
    1. User selects a dataset from storage.
    2. System extracts Schema + Statistics + Sample Segments.
    3. AI (Gemini/Groq) answers data-specific questions in natural language.

3. TECHNOLOGY STACK & ZERO-COST STRATEGY
To ensure the project remains 100% free for developers and users, we are implementing a Dual-Provider AI Strategy:

FEATURE                | PRIMARY PROVIDER             | FALLBACK PROVIDER
-----------------------|------------------------------|-------------------------
Logic/RAG              | Gemini 1.5 Flash (Free Tier) | Groq Llama 3.1 (Free Tier)
Database               | NeonDB (Serverless Postgres) | N/A
Frontend               | React + Recharts             | N/A

Switching Strategy: If Gemini hits a rate limit or becomes unresponsive, the system automatically redirects requests to Groq, ensuring 99.9% uptime at zero cost.

4. IMPLEMENTATION MILESTONES

Milestone 1: The AI Dashboard Engine (Backend)
- Setup ai.routes.js.
- Implement CSV metadata extraction.
- Build the AI prompt logic to return valid Recharts JSON configurations.

Milestone 2: Power BI Studio Upgrade (Frontend)
- Integrate Recharts into the Studio Canvas.
- Implement layout saving/loading from PostgreSQL.
- Enable "Draft Mode" for unsaved changes.

Milestone 3: RAG Insights Hub
- Create the dedicated Chat Section (/chat or side panel).
- Implement the "Context Constructor" (packaging data for the AI).
- Add "Pinned Insights" (AI text snippets can be pinned to the dashboard).

5. OPEN QUESTIONS FOR TEAM APPROVAL

1. Default Layout: Should the AI suggest a fixed number of charts (e.g., exactly 6) or calculate the quantity based on the importance of the columns?
2. RAG Scope: Should the AI have access to all datasets simultaneously, or should the user select one "Active Dataset" for the chat session?

6. VERIFICATION & QUALITY ASSURANCE
- Functional: Each auto-generated chart must accurately reflect the values in the CSV.
- Aesthetic: Dashboards must match the clean "Business" look of the provided samples (KPIs at top, charts below).
- Performance: AI responses must return within < 5 seconds.
